# Control de gastos

App web privada (PWA) para controlar gastos e ingresos: movimientos manuales, fijos mensuales o de meses concretos (nómina, pagas extra, suscripciones), calendario y análisis por día, semana, fin de semana, mes y año.

- HTML + CSS + JS sin framework
- Datos en Supabase (login + RLS: solo el usuario propietario ve sus datos)
- Instalable en Android y ordenador
